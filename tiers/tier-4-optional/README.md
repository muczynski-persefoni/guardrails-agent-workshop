# Tier 4 Optional: Break the Agent

This optional section is a facilitated failure-analysis exercise. It is separate from the required three-tier operating workflow.

The materials here are used after the core Tier 1–3 demonstrations:

- `break-the-agent.md` — participant instructions
- `break-the-agent-facilitator.md` — facilitator answers and teaching points
- `break-the-agent-script.md` — spoken presentation script
- `worksheet.md` — participant worksheet for the three failure scenarios

Use the participant instructions and worksheet before revealing the facilitator guide or script.
