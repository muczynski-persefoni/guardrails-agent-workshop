# Tier 3 PR Review Reports

This directory is reserved for evidence reports produced during the Tier 3 pull-request workflow.

Expected artifacts:

- `build-report.md`
- `review-intake.md`
- `agentic-review.md`
- `repair-summary.md`
- `evaluate-merge-readiness.md`

Each report identifies the PR number and exact head SHA it describes. Open the reports in Chrome with MarkView. Follow-up prompts are generated live by the orchestrator and are not stored in `tier-3-prompts.md`.
