# Tier 2 Report Workspace

This directory is reserved for the Markdown reports created during the Tier 2 orchestration demo.

Expected live artifacts include:

- `alpha-report.md`
- `beta-report.md`
- `gamma-report.md`
- `orchestrator-review.md`

The reports are generated during the session and can be opened in Chrome with MarkView. Follow-up prompts are created live by the orchestrator and are not stored in the initial prompts document.
